SINU CONTROL - Gastrobar Sinu, Bello

REQUISITOS (solo la primera vez):
  - Python 3.11 o superior (marcar "Add python.exe to PATH")
  - Node.js LTS
  - MySQL 8 encendido, con un usuario que pueda crear bases de datos

PARA INICIAR:
  1. Descomprima esta carpeta.
  2. Doble clic en "INICIAR SINU.bat" (la primera vez tarda 1-3 minutos).
  3. La primera vez se abre api\.env: complete DB_USER y DB_PASSWORD de MySQL,
     guarde y vuelva a ejecutar "INICIAR SINU.bat".
  4. Se abre http://localhost:5173

USUARIOS DE PRUEBA: ver README.md, seccion "Usuarios de prueba".

PARA APAGAR: cierre las ventanas "SINU API" y "SINU Frontend".
